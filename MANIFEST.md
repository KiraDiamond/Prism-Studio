# Gemini Instances Redesign Bundle

This is a direct file extraction of the Gemini implementation supplied by the user.
The code has NOT been corrected or merged into the Prism Studio repository.

## Files
- `ui/index.instances.proposal.html` — proposed Instances screen HTML section, not necessarily a full replacement for `ui/index.html`
- `ui/instances.js` — proposed shared state/filter/sort/render logic
- `ui/style.instances.proposal.css` — proposed CSS section, not necessarily a full replacement for `ui/style.css`

## Important
Gemini itself included placeholders such as:
- `get_instances`
- `launch_instance`
- `createNewInstance()`
- `openInstanceMenu(...)`
- fallback artwork/icon paths

These must be checked against the real Prism Studio repository before merge.
